## 一、什么是自定义域名邮箱转发？（原理与名词解释）

很多独立博客、个人站点展示的联系邮箱为 `contact@xxx.com` 这种**带自己域名的邮箱**，并非购买了付费企业邮箱。

该技术官方标准名称：**Cloudflare Email Routing（Cloudflare 电子邮件路由）**

通俗名称：域名邮箱转发、隐私别名邮箱、自定义域名收件邮箱。

**工作机制：**

1. 你对外公开：`contact@你的域名.com`

2. 用户发送邮件 → Cloudflare 官方邮件服务器接收

3. Cloudflare 自动转发到你的**真实私人邮箱**

4. 对方全程无法获取你的真实邮箱地址

**核心价值：**

- 完全隐藏个人真实邮箱，防止爬虫、垃圾邮件、隐私泄露

- 博客、作品集、商务场景更专业

- 无限创建别名邮箱，免费、稳定、无需服务器

## 二、前置条件

- 拥有顶级域名

- 域名 DNS 托管在 Cloudflare

- 可正常使用的私人邮箱（QQ / OutLook / Gmail 均可）

## 三、正式配置 Cloudflare Email Routing

### 1\. 开启邮件路由服务

1. 进入 Cloudflare 首页

2. 左侧菜单：**计算 -> 电子邮件服务 -> 电子邮件路由**

3. 点击 **接入域名**，选择自己的域名接入

![][1]

4. 验证并激活

![][2]

### 2\. 添加并验证「目标邮箱」

目标邮箱 = 你的真实收件邮箱（对外绝对不可见）

1. 切换到 **目标地址**

2. 输入自己的邮箱，点击**添加地址**

![][3]

3. 前往邮箱收件箱，点击 Cloudflare 验证链接

状态变为「已验证」即为配置成功。

### 3\. 创建博客专属域名邮箱（路由规则）

此处创建你对外展示的公开邮箱，例如：`contact@你的域名.com`

1. 进入 **路由规则** -> **创建路由规则**

2. **电子邮件匹配模式**：填写前缀，如 contact / admin / business

3. **操作**：发送到电子邮件

4. **目标地址**：选择已验证的私人邮箱

![][4]

保存后即刻生效。

### 4\. 关于 Catch\-all 通配转发（严谨避坑）

Cloudflare 支持`*@域名` 全部转发。

**个人博客不推荐开启**：

- 会大量接收全网垃圾邮件、爬虫扫描邮件

- 无收益，只会增加垃圾邮件干扰

固定配置单个 `contact@` 最为安全干净。


## 四、如何使用域名邮箱「回复邮件」

**重要知识点：Cloudflare Email Routing 仅负责收信，不提供 SMTP 发信。**

两种标准解决方案：

### 方案一：邮箱自带「自定义发件人」（简单）

在 QQ邮箱 / OutLook 设置中添加发件地址为`contact@域名.com`。

缺点：部分场景会被判定为代发，有概率进垃圾箱。

### 方案二：Resend 免费 SMTP

使用 Resend 提供的免费域名发信服务（每月 3000 封免费）

1. 注册 Resend 并添加域名

2. 完成 DNS 所有权验证

3. 获取官方 SMTP 配置

4. 在个人邮箱配置 SMTP 发信

可完美实现：**收件、发件全程使用自定义域名邮箱**。

## 五、测试方法

使用任意第三方邮箱发送测试邮件到你的`contact@域名.com`

成功标准：

- 正常收到邮件

- 对方看不到你的真实收件邮箱

## 六、常见问题

### 1\. 收不到邮件

- 检查是否存在多条 MX 记录

- 确认 Cloudflare 安全级别未拦截邮件爬虫

- 等待 DNS 完全生效

### 2\. 邮件进垃圾箱

- SPF 记录重复或错误

- 未使用官方 SMTP 发信

### 3\. 隐私安全性说明

全程真实邮箱不暴露在网页、邮件头、源代码中，是目前个人博客**隐私最优、成本最低**的邮箱方案。

## 七、博客使用

在你的博客「关于 / 联系我」页面放置：

- 公开邮箱：`contact@你的域名.com`

- 隐藏个人 QQ / 手机 / 私人邮箱
