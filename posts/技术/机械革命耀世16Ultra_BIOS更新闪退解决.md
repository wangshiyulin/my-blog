机械革命笔记本电脑在更新 BIOS 时，部分用户可能遇到更新程序启动后直接闪退、无法正常执行更新的问题。本文以 **2025 款机械革命耀世 16 Ultra** 为例，介绍一种通过 XMG BIOS 进行中转刷写，再更新至机械革命官方 BIOS 的解决方法。

对于这一问题，有观点认为可能与出厂 BIOS 的版本限制或更新程序的校验机制有关（简称锁定BIOS版本），但目前没有足够证据确认具体原因，询问客服也只会让你找售后。

本文介绍的是一种特殊情况下的替代方案：**先通过 EFI Shell 刷入经过兼容性确认的 XMG BIOS，再使用机械革命官方更新工具刷入目标版本。**

需要注意，这种方式存在一定风险，不保证适用于所有机械革命笔记本。

---

## 一、准备工作
开始操作前，需要准备以下文件和设备：

1. **XMG BIOS 更新文件**：从 XMG 官方固件下载渠道获取。需要核实对应机型的硬件平台、主板标识、BIOS 及 EC 兼容性。
2. **FAT32 格式的 U 盘**：用于存放 XMG BIOS 更新文件。
3. **机械革命官方 BIOS 更新工具**：联系机械革命官方客服，获取与自己电脑型号对应的 BIOS 更新程序。
4. **电源适配器**：更新期间需要保持电脑正常供电。

XMG 官方下载及帮助页面：

- [XMG 官方支持中心](https://www.xmg.gg/en/support/)
- [XMG 官方 BIOS 更新说明](https://help.xmg.gg/hc/en-gb/articles/17824611001117-How-can-I-update-the-EC-BIOS-firmware-of-my-laptop)
- [机械革命耀世 16 Ultra 官方技术支持](https://www.mechrevo.com/cn/products/yao-shi-16-ultra/supports)

**注意：BIOS 文件必须与设备硬件平台兼容。**

建议**备份电脑中重要数据**，确保在更新过程中不会因意外情况导致数据丢失。

## 二、更新前的设置
### 1. 处理 Windows 设备加密

在更新 BIOS 前，首先需要检查 Windows 是否开启了设备加密或 BitLocker。

因为 BIOS 更新、安全启动配置变更等操作可能改变系统的启动环境，导致 Windows 在下次启动时要求输入 BitLocker 恢复密钥。

对于 Windows 11，进入：

**设置 → 隐私和安全性 → 设备加密**

如果设备加密处于开启状态，可以按照原方案将其关闭，并等待磁盘解密完成。

![](/images/uploads/2026/10/2026-10-24_23-29-42.webp)

**务必事先保存 BitLocker 恢复密钥，并确保在电脑无法启动时仍可从其他设备访问。**

### 2. 检查当前 BIOS 版本
按下 `Win + R`，输入：

```text
msinfo32
```

回车打开“系统信息”，找到 **BIOS 版本/日期**，确认当前版本。

## 三、更新 BIOS
以下流程以准备好的固件包中包含 EFI Shell 刷写脚本 `flash1.nsh` 为前提。不同固件包可能采用不同的目录结构、启动方法和脚本名称，应以对应固件包的正式说明为准。

### 1. 将 XMG BIOS 文件放入 U 盘

首先，将 U 盘格式化为 **FAT32** 格式。

然后，解压下载好的 XMG BIOS 更新文件，将解压后的文件按固件包说明放入 U 盘。注意不要随意改变固件文件与刷写脚本之间的目录结构。

![](/images/uploads/2026/10/2026-10-24_23-31-26.webp)

完成后，将 U 盘插入电脑。

### 2. 进入 BIOS 设置界面

重启电脑，在开机过程中连续按下 `F2` 键，进入 BIOS 设置界面。

找到 **Secure Boot（安全启动）** 选项，设置为 `Disabled`。

保存 BIOS 设置并退出，电脑随后会重新启动。

### 3. 进入 EFI Shell

重启后一般会进入 EFI Shell 界面。

进入 EFI Shell 后，需要找到存储 XMG BIOS 文件的 U 盘。

可以使用以下命令列出文件：

```text
ls
```

如果当前不在 U 盘目录，使用：

```text
map -r
```

刷新并查看 EFI Shell 中的设备映射信息。

一般可以看到类似 `fs0:`、`fs1:` 的文件系统标识，查看其中的文件。如果不是 U 盘，就检查其他文件系统。

确认找到 U 盘后，按照实际目录结构进入存放 BIOS 更新脚本的文件夹。

可以使用 `cd` 命令切换目录。

**执行刷写脚本前，必须确认当前位置、脚本名称及固件文件均正确。**

### 4. 执行 BIOS 更新脚本

找到包含 `flash1.nsh` 的目录后，输入：

```text
flash1.nsh
```

按下回车，一路yyyy...（全部同意），回车后，等待 BIOS 更新程序执行。

**！！整个更新过程中：**

- 不要关闭电脑，也不要强制重启。
- 不要拔掉电源适配器或 U 盘。
- 不要操作键盘、鼠标或随意移动电脑。
- 如果屏幕短暂黑屏、风扇转速发生变化或者设备自动重启，不要立即判断为更新失败。

BIOS 更新可能持续一段时间，实际耗时取决于设备及固件更新流程。应等待程序正常完成。

### 5. 等待电脑重新启动

完成 BIOS 刷写后，电脑通常会自动重启。

正常情况下，设备会重新进入 Windows 系统，有时也可能出现红色提示页面或其他启动提示。

如果出现这种情况，首先阅读屏幕上的具体提示内容，按照提示点击 `OK`，尝试继续进入系统。

这个问题一般都是因为重启时没有拔下U盘导致的。

但是，**不能将所有红色报错都视为正常现象**。如果提示涉及 BIOS 校验失败、固件损坏或者系统无法启动，应记录错误内容并联系技术人员，不要反复强制重启。

### 6. 检查 BIOS 版本

成功进入 Windows 后，在确认更新程序已经结束的情况下，拔掉 U 盘，重启电脑。

随后按下 `Win + R`，输入：

```text
msinfo32
```

在系统信息中找到 **BIOS 版本/日期**，检查 BIOS 是否已经变成预期版本。

## 四、更新至机械革命官方 BIOS

如果上述刷写成功，并且电脑能够正常启动，就可以根据此前获得的机械革命官方更新工具，尝试更新到目标官方 BIOS 版本。

刷写机械革命官方 BIOS 的过程中，同样需要保持稳定供电，不要手动关闭更新程序或者强制重启。

如果官方程序依然出现闪退或提示不支持当前固件，应停止尝试，记录报错信息并联系官方客服。

---

## 五、更新完成后的检查

完成更新并正常进入 Windows 后，检查以下内容：

**1. 确认 BIOS 版本**

通过 `msinfo32` 检查最终版本是否与预期一致。

**2. 恢复 Secure Boot**

如果之前为了执行 EFI Shell 更新而关闭了 Secure Boot，建议在确认系统启动正常、已保存 BitLocker 恢复密钥的情况下，进入 BIOS 将其恢复到原来的设置。

**3. 恢复设备加密保护**

如果之前关闭了设备加密，则可以根据需要重新启用 Windows 的设备加密功能。

## 六、常见问题

### 1. 为什么运行机械革命 BIOS 更新工具会闪退？

目前无法单凭闪退现象确定原因，可能与更新程序本身、系统环境、固件版本校验或者设备当前固件状态有关。

但我见过最多的就是锁定了BIOS版本。

### 2. 所有机械革命电脑都可以使用 XMG BIOS 吗？

不一定，本文仅介绍针对特定设备的一种处理思路，选择固件时，必须核对完整硬件平台信息。

### 3. 更新 BIOS 后无法进入 Windows 怎么办？

首先观察电脑是否仍然能够进入 BIOS 设置界面。

如果能够进入 BIOS，记录屏幕上的错误提示，并检查启动项等设置是否发生变化。

如果电脑完全无法正常启动，或者 BIOS 刷写过程中出现严重错误，建议联系官方售后或专业维修人员处理，不要随意重复刷写不同固件。

### 4. 更新 BIOS 会删除电脑中的文件吗？

正常的 BIOS 更新一般不会直接清除 Windows 系统中的个人文件。

但是，固件更新可能改变启动设置、触发 BitLocker 恢复，严重的刷写失败也可能导致系统无法启动。

因此，更新 BIOS 前仍然建议备份重要数据。
